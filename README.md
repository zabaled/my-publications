## Published Research

### Localizing Failures in AI Agent Pipelines with Structured Execution Traces

**Author:** Alexey Zabegin  
**Journal:** American Impact Review  
**Publication Type:** Original Research  
**Published:** April 30, 2026  
**DOI:** [10.66308/air.e69362342](https://doi.org/10.66308/air.e69362342)

### Research Overview

This study investigates failure localization in AI agent pipelines using structured execution traces.

Failures in large language model applications can become visible several steps after the originating error, making root-cause identification challenging.

The research evaluates whether preserving structured execution-trace field identities improves failure localization compared with flattened textual representations.

### Research Dataset

The evaluation includes:

- **219** failed agent executions
- **5,936** candidate execution steps
- **173** task groups
- **3** AI agent systems
- **5** task-grouped evaluation folds

### Key Findings

- Separate-field encoding achieved 24.7% exact Top-1 localization accuracy.
- Flat representation achieved 23.3% exact Top-1 accuracy.
- Top-3 coverage increased from 46.6% to 50.7%.
- A combined ranking approach placed the annotated failure step within the selected quarter of records in 67.6% of traces.
- Field separation alone did not demonstrate a clear improvement in exact failure localization.

The results support the use of structured execution traces for lightweight diagnostic triage.
